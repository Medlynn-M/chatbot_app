# AI-Driven Inventory Management Chatbot

This repository contains the conversational AI chatbot for the capstone project: **AI-Driven Stockout Risk Optimization for Smarter Retail Inventory Management**.

The chatbot is designed to assist retail teams in querying inventory data, understanding stockout risks, and receiving actionable recommendations—making smarter decisions through natural language interaction.

## ⚡ Features

- **Conversational interface:** Ask questions about stockout risks, inventory status, sales forecasts, etc.
- **Smart insights:** Get contextual answers driven by AI and underlying data analytics.
- **Integration-ready:** Can be linked to model results, dashboards, or retail systems.
- **Extensible & customizable:** Supports new intents and can connect with APIs or databases as needed.
